# SocialPod Wiki

SocialPod is a self-hosted social media scheduling platform for **Bluesky**, **Instagram**, **X (Twitter)**, **Mastodon**, **Threads**, **LinkedIn**, and **YouTube**. It ships as a single Docker-based binary with a built-in React UI, background scheduler, image and video editor, REST API, MCP server, and native n8n integration.
